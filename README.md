# 🌀 Weather - Typhoon Tracking

紀錄颱風動態與災情的 Markdown 倉儲。

## 📋 專案說明

本專案專門記錄西北太平洋颱風季的颱風動態、災情彙整與相關資訊。以結構化的 Markdown 檔案格式，完整追蹤每個颱風的形成、路徑、強度變化、影響範圍與後續災情。

**核心目的**：記錄目前正在發生的天氣事件與即時災情彙整。

## 📁 目錄結構

```
weather/
├── AGENTS.md          # AI 助手專案指引
├── README.md          # 本檔案
├── 颱風/              # 颱風追蹤檔案
│   └── {YYYY}/
│       └── {MM}/
│           └── {MMDD}_{NN}_{中文名}_{國際命名}.md
└── 災情/              # 非颱風類型災情報告
    └── {YYYY}/
        └── {MM}/
            └── {MMDD}_{事件類型}_{事件名稱}.md
```

**範例**：
- 颱風檔案：`颱風/2026/07/0702_09_巴威_BAVI.md`
- 災情檔案：`災情/2026/08/0821_低壓帶_南台灣大雨.md`

### 目錄與檔名規則

| 元素 | 說明 | 範例 |
|------|------|------|
| `{YYYY}` | 年份 | 2026 |
| `{MM}` | 月份 | 07 |
| `{MMDD}` | 生成日期（月+日，補零） | 0702 |
| `{NN}` | 颱風編號（補零） | 09 |
| `中文名` | 台灣中央氣象署命名 | 巴威 |
| `國際命名` | 英文名稱 | BAVI |

**排序說明**：檔案名稱以生成日期和颱風編號為前綴，確保在目錄中按時間順序自然排列。

## 📝 檔案撰寫規則

### 基本規範

- 全部使用**繁體中文**
- 時間戳須含年與時間，如 `2026/7/10 05:30`
- 災害分級標籤：
  - 🔴 重大
  - 🟡 警戒
  - 🟢 一般
- 新進展**附加**在檔尾，不覆寫既有內容（僅在結構錯誤時修改）
- 颱風基本資料表（強度、風速、半徑等）置於檔首，使用表格
- **每次修改**必須在檔首（基本資料表上方）新增一筆 `最後修改：YYYY/M/D HH:mm`

### 章節結構

依序包含以下章節：

1. **基本資料** - 颱風編號、強度、風速、氣壓等
2. **警報時程** - 各氣象單位發布警報的時間點
3. **停班停課** - 中國大陸地區與台灣地區分開列出
4. **風力預測** - 各區域風力預測
5. **雨量預測** - 各區域雨量預測
6. **災情紀錄** - 依 🔴🟡🟢 分節，台灣與中國大陸分開
7. **交通影響** - 航空、海運、陸運等
8. **防災作為** - 各單位防颱措施
9. **備註** - 補充說明與歷史對照

## ⚠️ 時間意識

**撰寫或查詢災情前，必須先確認目前的現實時間（系統時間）。**

- 只關注**當前事件**相關的最新報導
- 檔案中的時間戳必須與現實時間一致
- 主動過濾歷史資料，避免誤植
- 每次新增災情前，確認該災情是否屬於「目前正在發生」的颱風事件

## 🛠️ 技術規格

- **版本控制**：Git（預設分支：`main`）
- **格式**：Markdown
- **語言**：繁體中文
- **無 CI/CD**：無自動化測試或建置流程
- **無 Linter**：無程式碼格式化工具

## 📊 資料內容

每個颱風檔案記錄以下資訊：

| 項目 | 說明 |
|------|------|
| 基本資料 | 國際編號、強度、風速、氣壓、半徑 |
| 警報時程 | 海警、陸警發布與解除時間 |
| 停班停課 | 中國大陸與台灣地區分別列出 |
| 風力雨量 | 各區域預測數據 |
| 災情紀錄 | 依嚴重程度分級記錄 |
| 交通影響 | 航空、海運、陸運中斷情況 |
| 防災作為 | 政府與單位應對措施 |

## 🌏 影響範圍

本專案記錄的颱風影響地區包括：

- **台灣地區**：台灣本島、澎湖、金門、馬祖、東沙島、恆春半島等
- **中國大陸**：廣東、福建、浙江、海南等省份
- **港澳地區**：香港、澳門
- **其他**：菲律賓、日本等西北太平洋沿岸國家

## 📅 使用方式

1. **查詢颱風紀錄**：依 `颱風/{年份}/{月份}/` 目錄查找
2. **追蹤當前颱風**：查看最新月份的檔案
3. **歷史對照**：比較不同年份同月份颱風活動
4. **災情統計**：從災情紀錄章節彙整災害資訊
